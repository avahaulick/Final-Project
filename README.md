## Branch workflow

- Keep `main` nearly empty except for the initial setup commit.
- Build Stage 1 work on `stage-1-frontend-and-api`.
- Create later stages in their own branches off `main` unless the project instructions say otherwise.

## Available scripts

- `npm run dev`
- `npm run build`
- `npm run lint`
- `npm run deploy`
